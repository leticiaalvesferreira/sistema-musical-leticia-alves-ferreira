# 🎵 Sistema Musical — Projeto do Semestre

Projeto prático desenvolvido para simular o fluxo de trabalho de software, criando uma aplicação completa de catálogo e gerenciamento musical (estilo Spotify). 

## 📌 Sobre o Projeto

O objetivo do sistema é estabelecer a relação entre um **Criador** (Artista/Banda) e suas **Obras** (Músicas/Álbuns). O projeto serve como base estrutural para diferentes domínios de aplicação (Livros, Filmes, Jogos, Receitas, Podcasts).

### 🚀 Escopo das Sprints

- [x] **Sprint 1 (Atual):** Front-End estático construído com HTML5 e CSS3 puros (Interface do usuário).
- [ ] **Sprint 2 (Futura):** Back-End e persistência de dados utilizando PHP e Banco de Dados.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica das páginas.
- **CSS3:** Estilização, layout responsivo e alinhamentos.
  - `Flexbox` para alinhamento e centralização de elementos.
  - `CSS Grid` para organização de menus e exibições em grade.
